## 🚀 Getting Started

### Prerequisites

Before running the projects, make sure you have installed:

- [Android Studio](https://developer.android.com/studio)
- Android SDK
- JDK compatible with the project's Gradle version

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/BulatNS31/AndroidProjectsUniversity.git
   ```

2. Open the repository in Android Studio.

3. Navigate to the laboratory assignment you want to work with.

4. Open the corresponding Android project.

5. Wait for Gradle synchronization to complete.

6. Run the project using an Android Emulator or a physical Android device.
